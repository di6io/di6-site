# DI6 Website — Repositioned version

Static GitHub Pages site for **di6.io**.

## Positioning
DI6 is a market growth studio helping brands enter, reposition and grow in the U.S. and Middle East through:
- Market strategy
- Social & content
- Creators & campaigns

Creator intelligence and AI-assisted research remain core capabilities, but are not the only identity of the company.

## Pages
- `/` — English international-facing website
- `/cn/` — China-facing Chinese sales version (localized, not literal translation)

## Deploy
Upload/commit all files and folders to the root of the existing `di6-site` GitHub repository on the `main` branch. Keep the existing `CNAME` file.

GitHub Pages should redeploy automatically.
